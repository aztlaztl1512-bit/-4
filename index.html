الكفاية الاتصالية: مهارات الكتابة الموضوعية

تطبيق مراجعة وتدريبات تفاعلية لمادة الكفايات اللغوية (الوحدة التدريبية الرابعة)

الفصل الأول: الفنون التعبيرية وعناصرها الفنية وخصائصها

1. المقال

العناصر: عنوان (قصير ومثير ودال)، مقدمة (قصيرة ومشوقة تمهد للموضوع)، عرض (فقرات تعبر كل فقرة عن فكرة رئيسية مع أفكار جزئية)، وخاتمة.

الخاتمة تلخص أهم ما جاء في المقال، أو تقدم حلاً لمشكلة، أو تقدم توصية.

2. القصة

العناصر: الزمان والمكان، الشخصيات، الأحداث، الحبكة والعقدة، الحل والسرد والحوار.

تمتاز بترابط الأحداث والتشويق.

3. الرسائل الإدارية (الرسمية)

العناصر: البسملة، التاريخ، بيانات المرسل والمرسل إليه، التحية، موضوع الرسالة، الخاتمة، والتوقيع (والمرفقات إن وجدت).

تمتاز بالوضوح والإيجاز والرسمية.

4. التقرير

العناصر: عنوان، مقدمة تبين الهدف، عرض منظم للحقائق، وخاتمة تتضمن النتائج والتوصيات مع بيانات معد التقرير وتاريخه.

يمتاز بالدقة والموضوعية.
الفصل الثاني: خطوات بناء الموضوع (المراحل السبع للكتابة)

1. اختيار الموضوع

معلوماتك عنه جيدة، أو يمثل جزءاً من اهتماماتك، أو يهم القراء، أو لديك إضافات عنه.

2. تحديد الهدف

التعبير عن الذات (عاطفة/رأي)، إنشاء علاقات اجتماعية، أو معالجة معلومات (توضيح، إضافة، تلخيص...).

3. جمع المعلومات وتصنيفها

المصادر: الكتب، الصحف، المجلات، الإنترنت، المقابلات، والخبرة الشخصية. ثم تصنيفها في أبواب أو أفكار رئيسية.

4. التخطيط للموضوع

تصميم مخطط الموضوع وتنظيمه قبل البدء بالتنفيذ المباشر.

5. الكتابة الأولى (المسودة)

التركيز على عرض المعلومات واستيفائها مع الاهتمام بجودة بناء الفقرات دون توقف فوري للتعديل.

6. المراجعة

التأكد من صحة اللغة والإملاء، علامات الترقيم، منطقية تسلسل الأفكار، وجمال الأسلوب وقوة التأثير والإقناع.

7. الكتابة النهائية (المبيضة)

كتابة النسخة الأخيرة مع الاهتمام بجودة الإخراج وتناسق الهوامش والوضوح.

الفصل الثالث: مهارات بناء الموضوع التفصيلية

1. اختيار العنوان

الشروط: قصير، مثير، ودال على المحتوى.

2. بناء المقدمة

قصيرة، مشوقة، وتمهد للموضوع بأسلوب جاذب.

3. الكتابة في فقرات

تبدأ كل فقرة بفراغ بمقدار كلمة وتنتهي بنقطة (.)، وتعبر كل فقرة عن فكرة واحدة.

4. تسلسل الأفكار

تسلسل منطقي أو زمني، بحيث تمهد كل فكرة لما بعدها وتكمل ما قبلها.

5. بناء الخاتمة

تلخيص الأفكار، أو تقديم توصيات ومقترحات، أو تبيان الرأي النهائبي للكاتب.

الفصل الرابع: تصميم مخطط الموضوع ورسوم التخطيط

عناصر تصميم المخطط

1. تحديد العناصر الفنية بحسب نوع الفن.
2. تحديد الأفكار الرئيسة لكل عنصر.
3. تحديد الأفكار والجزئيات التفصيلية.
4. اقتراح أسلوب العرض، وأساليب التأثير والإقناع، وشواهد الدعم.

رسوم التخطيط الهيكلية

يمكن تلخيص مخطط الموضوع قبل الكتابة باستخدام: شجرة الذاكرة، أو مخطط هيكل السمكة، أو الجداول التوضيحية.
